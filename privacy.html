Privacy Policy / 개인정보처리방침

Last updated: 2026-10-28

What data is accessed

When the user links a Google account, PKM YouTube requests the read-only scope https://www.googleapis.com/auth/youtube.readonly and reads: the user's YouTube subscription list (channel IDs, titles, thumbnails) and the user's own channel name and avatar.

How it is used

The data is used only to display the user's subscriptions and new videos from those channels inside PKM on the user's own TV device.

Storage

OAuth tokens and the subscription list are stored only on the user's own device (Kodi add-on data folder). Nothing is sent to any server operated by the developer; the add-on only talks to Google/YouTube APIs and public YouTube RSS feeds.

Sharing

The data is not sold, shared or transferred to any third party, and is not used for advertising.

Deletion / revoking access

The user can unlink the account at any time in PKM (YouTube 설정 → 계정 연결 해제), which deletes the stored tokens and subscription list from the device and revokes the token. Access can also be removed at myaccount.google.com/permissions.

Google API Services User Data Policy

PKM YouTube's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.
