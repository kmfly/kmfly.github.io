PKM YouTube

PKM YouTube is a personal add-on for the Kodi media center (PKM skin) running on an NVIDIA Shield TV. It shows YouTube videos, search results and the user's own subscriptions in a TV-friendly layout and hands playback to the official YouTube app.

PKM YouTube는 NVIDIA Shield TV의 Kodi(PKM 스킨)에서 동작하는 개인용 애드온입니다. 유튜브 영상, 검색 결과, 사용자 본인의 구독 채널을 TV 화면에 맞게 보여 주고, 재생은 공식 YouTube 앱으로 넘깁니다.

Google account access / 구글 계정 사용

  • Sign-in uses Google's OAuth device flow (google.com/device) with the read-only scope youtube.readonly.
  • It reads only the signed-in user's subscription list and channel name/avatar, to show them inside PKM on the user's own TV.
  • It never posts, comments, subscribes, unsubscribes or changes anything in the account.
  • 읽기 전용 권한으로 본인의 구독 목록과 채널 이름만 읽어 본인 TV에 표시합니다. 계정에 어떤 변경도 하지 않습니다.
